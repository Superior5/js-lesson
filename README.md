# Основы программирования — занятие 1

Учебное веб-приложение для студентов первого курса. Первая лекция знакомит с программами, алгоритмами, JavaScript, Node.js, числами и строками. В конце есть практическая и домашняя работа.

В проект также входит отдельная страница лабораторной работы по HTTP и Express:

```text
/http-lab-2
```

## Запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес приложения в терминале.

## Сборка

```bash
npm run build
```

## Структура

- `src/views/LessonOne.vue` — композиция страницы занятия;
- `src/views/HttpLabTwo.vue` — лабораторная работа по HTTP и Express;
- `src/components/` — переиспользуемые элементы интерфейса: шапка, навигация, секции, код, заметки и задания;
- `src/data/` — навигация и данные занятий;
- `src/styles/main.css` — темы, типографика и адаптивные стили.

Новые занятия можно добавлять как отдельные представления и наборы данных, переиспользуя существующие компоненты.
