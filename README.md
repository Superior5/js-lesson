# Основы программирования — занятия по JavaScript

Учебное веб-приложение для студентов первого курса. Материал знакомит с программами, алгоритмами, JavaScript и Node.js, а затем разбирает переменные, типы данных, операторы и условные конструкции.

## Маршруты

- `/` — перенаправление на первое занятие;
- `/1` — «Введение в программирование, JavaScript и Node.js»;
- `/2` — «Основы JavaScript: переменные, типы данных и операторы»;
- `/3` — «Условные конструкции и управление выполнением программы»;
- `/http-lab-2` — лабораторная работа по HTTP и Express.
- `/http-lab-3` — лабораторная работа по REST API и CRUD.

Для прямого открытия маршрутов в production nginx должен возвращать `index.html` для неизвестных файлов:

```nginx
try_files $uri $uri/ /index.html;
```

## Запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес приложения в терминале.

## Сборка

```bash
npm run build
```

## Структура

- `src/views/LessonOne.vue`, `src/views/LessonTwo.vue` и `src/views/LessonThree.vue` — страницы занятий;
- `src/views/HttpLabTwo.vue` и `src/views/HttpLabThree.vue` — лабораторные работы по Express;
- `src/components/` — переиспользуемые элементы интерфейса: шапка, навигация, секции, код, заметки и задания;
- `src/data/lessons.js` — метаданные и навигация занятий;
- `src/data/` — задания и дополнительные данные;
- `src/router/index.js` — маршрутизация;
- `src/styles/main.css` — темы, типографика и адаптивные стили.

Новые занятия можно добавлять как отдельные представления и наборы данных, переиспользуя существующие компоненты.
