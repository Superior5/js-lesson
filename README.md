# Основы программирования — занятия по JavaScript

Учебное веб-приложение для студентов первого курса. Материал знакомит с программами, алгоритмами, JavaScript и Node.js, а затем разбирает переменные, типы данных, операторы, условные конструкции, циклы, массивы и функции.

## Маршруты

- `/` — главная страница с выбором курса JavaScript или Express.js;
- `/1` — «Введение в программирование, JavaScript и Node.js»;
- `/2` — «Основы JavaScript: переменные, типы данных и операторы»;
- `/3` — «Условные конструкции и управление выполнением программы»;
- `/4` — «Циклы и повторение действий в JavaScript»;
- `/5` — «Массивы и коллекции данных в JavaScript»;
- `/6` — «Функции и декомпозиция программ в JavaScript»;
- `/express-js-1` — «HTTP и первый Express-сервер»;
- `/express-js-2` — «REST API и CRUD»: фильтрация, сортировка и пагинация;
- `/express-js-3` — «Middleware и Router: как проходит запрос» — первая часть для начинающих;
- `/express-js-4` — «Проверка данных и понятные ошибки» — вторая часть для начинающих.

Старые адреса `/http-lab-2` и `/http-lab-3` перенаправляют на `/express-js-1` и `/express-js-2` соответственно. Адресная строка меняется; query-параметры и якорь сохраняются. Внутренние ссылки используют новые адреса. Следующие занятия Express продолжают нумерацию `/express-js-5`, `/express-js-6` и т. д.

Для прямого открытия маршрутов в production nginx должен возвращать `index.html` для неизвестных файлов:

```nginx
try_files $uri $uri/ /index.html;
```

## Запуск

```bash
npm install
npm run dev
```

```bash
npm run build
```

## Структура

- `src/views/HomeView.vue` — главная страница с двумя плитками курсов;
- `src/views/LessonOne.vue`–`src/views/LessonSix.vue` — страницы занятий;
- `src/views/HttpLabTwo.vue`, `src/views/HttpLabThree.vue`, `src/views/ExpressJsThree.vue` и `src/views/ExpressJsFour.vue` — занятия Express № 1–4;
- `src/components/ExpressLessonPage.vue` — общий макет занятий Express № 3–4;
- `src/data/expressJsThree.js` и `src/data/expressJsFour.js` — учебные примеры, навигация, практика и вопросы занятий № 3–4;
- `src/components/` — переиспользуемые элементы интерфейса: шапка, навигация, секции, код, заметки и задания;
- `src/data/lessons.js` — метаданные и навигация занятий;
- `src/data/` — задания и дополнительные данные;
- `src/router/index.js` — маршрутизация;
- `src/styles/main.css` — темы, типографика и адаптивные стили.

Новые занятия можно добавлять как отдельные представления и наборы данных, переиспользуя существующие компоненты.

## Последовательность занятий Express

1. HTTP, клиент и сервер, методы, URL, JSON, статус-коды, первый GET и POST.
2. REST и CRUD, параметры пути, фильтрация, поиск, сортировка, пагинация, проверка входных данных вручную.
3. Middleware и Router: от сервера в одном файле к трём файлам. Пошагово разбираются req, res, next(), app.use(), express.json(), порядок обработчиков, import/export и общий префикс маршрутов.
4. Проверка данных и ошибки: тот же проект дополняется одним файлом схемы. Студенты знакомятся с Zod, safeParse, result.data, next(error), общим JSON-ответом и статусами 400/404/500.

Занятия № 3–4 рассчитаны на начинающих, примерно по 90 минут каждое. В них используются небольшие примеры товаров с полями title и price, объяснения строк кода, промежуточные работающие версии, проверки с ожидаемыми ответами, самостоятельная практика и домашние задания. В первом занятии итоговый проект состоит из трёх файлов, во втором — из четырёх.

Домашние задания продолжают API студентов из занятия № 2. В третьем занятии переносится существующая функциональность в Router; в четвёртом сначала улучшается проверка создания студента. Сложные фабрики middleware, сервисный слой, PATCH-схемы, схемы query и асинхронность оставлены для следующих отдельных занятий.
